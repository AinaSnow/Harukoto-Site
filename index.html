晴词Harukoto

一款输入不上云的中文拼音输入法，
顺手打日语，也认得艾欧泽亚的名字。

整句拼音、简拼混拼、模糊音与纠错；拼音或英语直出日语表记与假名；可选的 FF14 主题词库收录九万余条名称。输入内容只在本机处理，不上传。

下载试用版 试用前须知

输入不上云

词库、排序、学习记录全在本机。诊断工具也不记录你打过的字。

中文为本

整句拼音、简繁切换、简拼混拼、模糊音、手误纠错、选词记忆。

日语顺手打

拼音或英语触发日语词，表记与假名分开选，F6 查看活用形。

一个引擎，多开不重

所有应用共用一个后台引擎，词库只加载一份；多开应用时省内存、打字更快。

功能四个方向

01

中文输入

  • 整句拼音空格、数字选词；- = 或方向键翻页，选到页尾继续按自动翻页。可只选句首一部分，剩下的拼音继续组句。
  • 简拼与混拼nh → 你好，zgren → 中国人。
  • 模糊音与纠错z=zh、n=l 等按对开启；常见手误自动纠正，候选下标“纠错”。
  • 选词记忆与个人词选过的词以后优先，误选改选即可纠正；可加个人词，Ctrl+Delete 忘记学到的词，[ ] 以词定字。
  • 简体／繁体输出一键切换，主题词按词组转换。
  • 符号与快捷输入v+数字、vrq 日期、vsj 时间、vfh 列出全部符号分类；Ctrl+. 切标点，单按 Shift 切中英文。
02

日语辅助

  • 拼音、英语直出日语已收录的明确触发词可出日语，例如 riben → 日本／にほん、xuexiao → 学校／がっこう、chi 或 eat → 食べる／たべる、coffee → コーヒー。
  • 表记与假名分开两条独立候选，选哪条就只上屏哪条。
  • F6 活用面板（首版）高亮“食べる”按 F6，可选 食べます、食べて、食べない 等形式。

说明：这不是中译日的自动翻译，只覆盖已收录的触发词；个人日语词表可自行导入。

03

主题词库 · FF14

90,536 条名称 ＋ 71 条玩家用语

FF14 词库 0.5.0：物品、地名、技能、副本、NPC、怪物与 Boss、任务、坐骑、状态、特性、情感动作、PvP 技能等，按中日英同表 ID 对齐；以及团辅、团本、幻卡、光呆等玩家说法。

  • wuerdaha 乌尔达哈
  • sainiao 赛鸟／チョコボレース
  • danshua 单刷／ソロ
  • 团辅 → シナジー
  • 不抢日常首选与常用词同音的触发已过滤；常用读音的首选在 FF14 开／关下保持一致（项目评测）。
  • 可导入、启停、更新、回退主题包默认关闭，在“晴词主题词库”里导入启用。
  • 不需要 Python词库管理器内置到晴词里，导入、启用 FF14 词库直接可用。
  • 测试中游戏内实机抽查尚未完成；部分自动拼音可能有多音字误读。
04

Windows 体验与独立引擎

  • 独立引擎（默认开启）各应用只保留很小的输入客户端；引擎不可用、超时或词库不一致时，这段输入自动改由应用内计算，不丢已选文字。设置里可关闭。
  • 游戏内输入支持游戏自带候选框的系统接口（如 FF14）。实机测试中
  • 候选窗可调字号、宽度、布局可视化编辑，带实时预览；支持高 DPI 与远程串流显示。新版单行风格见外观。
  • 热更新词库与输入法更新在两段输入之间生效，多数情况下不必重开应用。
  • 诊断工具Diagnose.cmd（不记录输入内容）与候选来源说明 Explain.cmd。
  • 检查更新设置里手动检查，或开启每天自动检查（默认关闭）；只向 GitHub 查询发布信息，有新版时打开发布页，不自动下载安装。

外观单行候选窗，两种晴空风格

候选改为与系统输入法类似的单行横排：序号、词和读音在同一行，窗口随候选收窄，超过最大宽度才换行。风格与颜色在“晴词候选窗设置”里切换。alpha.36 起 · 实机测试中

  • 晴空 Fluent接近 Windows 11 面板：当前候选用系统强调色淡底加左侧竖条标出。
  • 晴空胶囊大圆角，每个候选是一枚淡色胶囊，当前候选变成实心晴空蓝。
  • 颜色跟随系统、浅色或深色；系统高对比模式下始终用系统颜色。

示意图按项目配色用 CSS 绘制，不是截图；Fluent 的强调色在实际使用中取自你的 Windows 设置。真实应用中的深浅色、阴影与光标贴合仍在实机测试中。

最近几版还带来

  • 启用 FF14 词库不再需要 Python词库管理器内置到晴词里。
  • 候选窗界面更新免重开只改外观的更新，在两段输入之间自动换上新界面（首次升级到该版本时仍需重开一次应用）。alpha.36 起。
  • 检查更新设置里一键检查；可选每天自动检查一次（默认关闭）。有新版时打开发布页，不自动下载安装。alpha.37 起。

以上功能已通过自动测试，真实应用中的效果仍在实机验证中。

安装三步

  1. 1

    下载并核对

    从 Releases 下载 Harukoto-<版本>-Setup.exe，核对页面上的 SHA-256：

    Get-FileHash .\Harukoto-0.4.4-alpha.37-Setup.exe
  2. 2

    双击安装

    点“安装 / 更新”，同意管理员授权。安装包未签名，Windows 会先拦一下，见下方试用版说明。

  3. 3

    重开应用，切换

    重新打开要打字的应用（已开着的不会加载新输入法），按 Win+空格 切到“晴词 Harukoto”。

系统要求：Windows 10／11 x64。启用 FF14 等主题词库不需要 Python。卸载在“设置 → 应用”中进行，个人词表和设置会保留。

示意

已知限制

  • 以管理员身份运行的程序和开始菜单搜索等沙箱程序不接入独立引擎，改用应用内输入：打字和候选不受影响，只是这个程序会多占一份词库内存，第一次打字稍慢。
  • 登录后第一次打字，后台引擎启动约 2 秒，这期间候选可能稍晚出现。
  • 从 alpha.35 或更早版本升级后，已经开着的应用要重开一次；之后只改候选窗外观的更新不用重开。
  • 只支持 Windows x64；没有 macOS／手机版本。

FAQ常见问题

会上传我打的字吗？

不会。候选计算、学习记录和个人词都在本机完成，不上传。诊断工具 Diagnose.cmd 也不记录输入内容。晴词唯一的联网是检查更新：只向 GitHub 查询发布信息，不带输入内容、个人词库或设备标识，默认只在你点按钮时进行。

为什么 Windows 说“已保护你的电脑”？

试用版安装包没有代码签名，SmartScreen 会拦截。核对发布页上的 SHA-256 后，点“更多信息 → 仍要运行”即可。

装好了但应用里切不出来／没变化？

已经开着的应用不会加载新输入法，请彻底退出后重开（像 QQ 这类常驻托盘的要从托盘退出）。然后按 Win+空格 切换。

怎么更新到新版本？

在“晴词候选窗设置”最下方点“检查更新”，有新版时会打开发布页；下载新的 Setup.exe 直接安装即可覆盖旧版，个人词表和设置会保留。也可以开启“每天自动检查一次”（默认关闭）。

FF14 词库怎么开？

默认不开。在开始菜单打开“晴词主题词库”，预览 FF14 词库 → 导入 → 启用，再重开游戏。不需要 Python（alpha.34 及更早版本需要）。

开了 FF14 词库会影响平常打字吗？

和常用词同音的触发已经过滤，项目评测中常用读音的首选在开／关词库时相同。少数读音下主题词会出现在第 2～3 位之后；遇到排得不对的词，可以用 Explain.cmd 查看原因并反馈。

独立引擎有问题怎么办？

引擎出问题时会自动改用应用内输入。也可以在设置窗口关闭“多个应用共用一个输入引擎”，下一次按键起生效，不需要重开应用。

支持 macOS 或手机吗？

目前只支持 Windows 10／11 x64。Android 源码保留但暂不发布，macOS、iOS 已移除。

晴词和 Meowpuut 是什么关系？
